# Screenshot Menu Bar App

macOS menu bar app for storing & displaying clipboard screenshots.

## Features
- Paste screenshot from clipboard
- Menu bar display on click
- Pop-out always-on-top window
- Auto-resize (max 800px)
- Persistent storage during session

## Setup
1. Open `ScreenshotMenuBar.xcodeproj` in Xcode
2. Select your development team in Signing & Capabilities
3. Build & run (Cmd+R)
4. Grant clipboard access if prompted

## Usage
1. Copy screenshot to clipboard (Cmd+Shift+4, then Cmd+C or use screenshot tool)
2. Click menu bar icon (photo icon)
3. Click "Paste from Clipboard"
4. Screenshot appears in popup
5. Use "Pop Out" for floating window
6. Click menu bar icon anytime to view

## Requirements
- macOS 13.0+
- Xcode 15+
- Apple Silicon (M1) or Intel Mac
